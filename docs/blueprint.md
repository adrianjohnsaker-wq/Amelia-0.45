# **App Name**: ModuleMind AI

## Core Features:

- Chat Interface: Interactive chat interface for users to communicate with the AI research model.
- Python Module Orchestration: Employ the LLM as a tool to intelligently orchestrate 100+ python modules in response to user prompts, utilizing the modules to enhance the AI's 'speaking' and 'thinking' capabilities.
- Module Upload: Enable users to upload custom Python modules to expand the AI's capabilities. Modules persist across sessions.
- Memory Upload: Allow users to upload memory in text or other document formats for enhanced recall, with memory stored as tokens.
- Module Directory: A searchable display of available modules to help the user choose.
- Web Scraper Integration: Integrate a web scraper to provide enhanced information flow and access for the AI.

## Style Guidelines:

- Primary color: Electric Purple (#BE29EC), evocative of cyberpunk themes and technological prowess.
- Background color: Near-black (#080509) for a dark, immersive, cyberpunk atmosphere.
- Accent color: Cyber Yellow (#D4F749), highlighting interactive elements with a jolt of futuristic energy.
- Utilize a grid-based layout for structured readability and clear information hierarchy.
- Font: 'Space Grotesk' (sans-serif) for headlines; 'Inter' (sans-serif) for body, to create a modern and readable interface. Note: currently only Google Fonts are supported.
- Employ neon-style icons for module categories and interactive elements, enhancing the cyberpunk aesthetic.
- Incorporate subtle animations for loading and transitions to maintain a smooth user experience.
